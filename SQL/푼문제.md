## 오프라인/온라인 판매 데이터 통합하기

```sql
select sales_date, product_id, user_id, sales_amount as sales_amount
from online_sale
where sales_date between '2022-03-01' and '2022-03-31'
union
select sales_date, product_id, null, sales_amount as sales_amount
from offline_sale
where sales_date between '2022-03-01' and '2022-03-31'
order by sales_date asc, product_id asc, user_id asc;

```

## 업그레이드된 아이템 구하기

```sql


select A.item_id, item_name, rarity
from item_info A
join item_tree B
on A.item_id = B.item_id
where parent_item_id in
    (select item_id from item_info where rarity = 'RARE')
order by item_id desc;
```

# group by

## 대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기

1. 내풀이

```sql
select month(start_date) as month, car_id, count(*) as records
from CAR_RENTAL_COMPANY_RENTAL_HISTORY
where car_id in
    (
    select car_id from CAR_RENTAL_COMPANY_RENTAL_HISTORY
    where start_date between '2022-08-01' and '2022-10-31'
    group by car_id
    having count(*) >= 5
    )
and start_date between '2022-08-01' and '2022-10-31'
group by month(start_date), car_id
having count(*) > 0
order by month, car_id desc;
```

2. with 두개

```sql
with A as (
    select history_id, car_id, start_date
    from CAR_RENTAL_COMPANY_RENTAL_HISTORY
    where start_date between '2022-08-01' and '2022-10-31'
),
B as (
    select car_id
    from A
    group by car_id
    having count(*) >= 5
)
select month(A.start_date) as month, A.car_id, count(*) as records
from A join B on A.car_id = B.car_id
group by month, car_id
order by month, car_id desc;

```

## 노선 별 평균 역 사이 거리 조회하기

```sql
select
    route,
    concat(round(sum(d_between_dist), 1), 'km') as total_distance,
    concat(round(avg(d_between_dist), 2), 'km') as average_distance
from subway_distance
group by route
order by sum(d_between_dist) desc;
```

- 이거 맨 마지막에 order by total_distance하면 안댐 concat해서 문자열돼서 정렬이상해짐

## 대장균들의 자식 수 구하기

```sql
with base as (
    select parent_id, count(*) as child_count
    from ecoli_data A
    where parent_id is not null
    group by parent_id
)
select A.id, ifnull(B.child_count, 0) as child_count
from ecoli_data A
left join base B
on A.id = B.parent_id
order by id;
```
